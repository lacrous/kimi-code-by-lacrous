Press a single key or a key combination.

Pass modifiers and the key together, in order: `["ctrl", "c"]` for Ctrl+C,
`["ctrl", "shift", "t"]` to reopen a closed tab, `["alt", "tab"]` to switch
windows. A single-element list is one bare key, e.g. `["Return"]` or `["Escape"]`.

Key aliases are accepted in any case: enter, esc, tab, backspace, space, up,
down, left, right, delete, home, end, pageup, pagedown, ctrl, alt, shift, super
(or cmd).
